# Software audio decoders

This app includes FFmpeg 6.0.1 (commit c41ff724ede7da657762d61097e26fac296c53bf), built without GPL, nonfree or external codec components, under LGPL 2.1 or later. Media3's JNI wrapper is Apache 2.0, commit c35a9d62baec57118ea898e271ac66819399649b (1.4.1). License texts are included in the APK assets and source bundle.

The matching GitHub Actions run includes the HY300-audio-sources artifact: exact upstream source archives and the build script. Run `bash scripts/build-audio-decoders.sh` with Android NDK 26.1.10909125 installed, then Gradle 8.2 with JDK 17: `gradle :decoder-ffmpeg:assembleRelease`. The resulting AAR contains replaceable libffmpegJNI.so libraries. The complete app build configuration is in this repository's codex/android12-low-memory branch. FFmpeg is unmodified. The Media3 JNI wrapper applies scripts/patch-truehd.py (included in the source bundle): initialize the TrueHD channel layout from the input format and preserve it on flush, addressing androidx/media#1843 and removing the old reset use-after-free path. You may modify/rebuild the library, replace the matching APK lib/<abi>/libffmpegJNI.so and re-sign/install your modified APK. Reverse engineering for debugging modifications to these libraries is permitted. Replacement apps require your own signing key and may require uninstalling the old app.

Enabled audio decoders: AAC, MP3 (including MPEG layers), AC3, E-AC3, DTS, TrueHD/MLP, Vorbis, Opus, FLAC, ALAC, AMR-NB/WB, G.711 A-law/mu-law. PCM also uses Android's normal path. Video remains hardware decoded to limit CPU usage on a 2 GB projector. DRM, malformed media, unavailable servers and formats outside Media3 extractors are not made universally compatible by adding audio decoders.

Container limitation: ALAC is supported in MP4/M4A, not Matroska, by the Media3 extractor used here. The software decoder alone does not add support to an extractor.
